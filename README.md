# پورتال بازطراحی‌شده کمیته امداد امام خمینی (ره)

نسخه بازطراحی‌شده و مدرن از پورتال [emdad.ir](https://www.emdad.ir/) با تمرکز بر زیبایی، سرعت، دسترسی‌پذیری و امکانات تعاملی.

## ✨ امکانات

### طراحی و تجربه کاربری
- **اسلایدر جذاب** با افکت Ken Burns، انیمیشن متن، نوار پیشرفت و کارت‌های شناور
- **انیمیشن‌های Framer Motion**: ظهور تدریجی هنگام اسکرول، شمارنده‌های متحرک آمار، انتقال نرم بین صفحات
- **۵ تم رنگی**: سبز امداد (پیش‌فرض)، فیروزه‌ای، بنفش سلطنتی، غروب مهر، طلایی نیکوکاری
- **حالت شب و روز** با ذخیره تنظیمات
- طراحی کاملاً **ریسپانسیو** (موبایل‌محور) و **RTL** کامل

### دسترسی‌پذیری (پنل توانخواهان) ♿
- انتخاب **فونت** (وزیرمتن، ساحل، صمیم، شبنم)
- **۴ اندازه متن** (کوچک تا بزرگ‌تر)
- **خواندن صفحه با صدا** (Text-to-Speech فارسی)
- کنتراست بالا، سیاه‌وسفید (نابینایان رنگی)، خط زیر لینک‌ها، فاصله‌گذاری متن (دیسلکسیا)، نشانگر بزرگ موس
- خاموش‌کردن انیمیشن‌ها + بازنشانی سریع

### اخبار و امتیازدهی ⭐
- **پنل مدیریت کامل**: نوشتن، ویرایش، انتشار/پیش‌نویس و حذف خبر با بارگذاری تصویر (فشرده‌سازی خودکار)
- **امتیازدهی ستاره‌ای** کاربران به هر خبر (۱ تا ۵) با محاسبه میانگین
- فیلتر بر اساس دسته، استان و جستجوی متنی + مرتب‌سازی (جدیدترین، بیشترین امتیاز، پربازدیدترین)
- شمارش بازدید هر خبر + دکمه «گوش دادن به خبر» و «اشتراک‌گذاری»

### خدمات با مشخصات کامل 📋
- ۱۱ خدمت اصلی (اکرام، معیشت، جهیزیه، وام، تحصیل، سلامت، مسکن، اشتغال، صدقه، زکات، ارتباط مردمی)
- مشخصات هر خدمت: مبلغ، شرایط، مدارک لازم، مراحل، زمان پاسخگویی و کانال دریافت
- فیلتر خدمات آنلاین

### سایر بخش‌ها
- آمار متحرک، مشارکت الکترونیکی (پذیرش حامی / پرداخت صدقه با شبیه‌سازی درگاه)
- ۳۱ استان، چندرسانه‌ای (۷ دسته)، ساختار سازمانی، سوالات متداول
- سامانه شفافیت، تماس با ما، جستجوی سراسری

## 🚀 اجرای پروژه

### روش ۱ — ویندوز (یک‌کلیکی) 🪟

پیش‌نیازها: [Node.js LTS](https://nodejs.org) و [Git for Windows](https://git-scm.com/download/win)

```bat
git clone https://github.com/sjalilvand/portal_em.git D:\Projects\portal_emdad
cd /d D:\Projects\portal_emdad
start-windows.bat
```

فایل `start-windows.bat` همه کارها را خودکار انجام می‌دهد: نصب وابستگی‌ها، آماده‌سازی دیتابیس، اجرای سرور و بازکردن مرورگر روی `http://localhost:3000`

### روش ۲ — ویندوز (دستورات دستی)

```bat
git clone https://github.com/sjalilvand/portal_em.git D:\Projects\portal_emdad
cd /d D:\Projects\portal_emdad
npm install
npx prisma generate
npm run dev
```

سپس `http://localhost:3000` را در مرورگر باز کنید.

### روش ۳ — لینوکس / مک

```bash
git clone https://github.com/sjalilvand/portal_em.git
cd portal_em
npm install
npx prisma generate
npm run dev
```

### نسخه Production (اختیاری)

```bash
npm run build    # ساخت نسخه بهینه + کپی خودکار فایل‌های استاتیک
npm start        # اجرای سرور روی .next/standalone/server.js
```

> 💡 دیتابیس SQLite همراه با ۱۰ خبر نمونه و امتیازها در مخزن (`db/custom.db`) قرار دارد و نیازی به seed مجدد نیست. در صورت نیاز: `npm run db:push` و سپس `node scripts/seed.js`

### ورود به پنل مدیریت اخبار
از منوی «بیشتر ← مدیریت اخبار» یا دکمه شناور دسترسی‌پذیری:
- رمز نمایشی: `emdad1404`

## 🛠 فناوری‌ها

| بخش | فناوری |
|-----|--------|
| فریم‌ورک | Next.js 16 (App Router) + TypeScript |
| استایل | Tailwind CSS 4 + shadcn/ui |
| انیمیشن | Framer Motion |
| دیتابیس | Prisma + SQLite |
| آیکون | Lucide Icons |
| فونت | وزیرمتن، ساحل، صمیم، شبنم (Self-hosted برای سرعت) |

## ⚡ نکات سرعت
- فونت‌های فارسی self-hosted با `font-display: swap`
- فشرده‌سازی خودکار تصاویر آپلودی (حداکثر عرض ۹۰۰px، JPEG با کیفیت ۷۸٪)
- Lazy loading تصاویر پایین صفحه + انیمیشن‌های `once: true`
- دیتابیس SQLite سبک با ایندکس امتیازها
